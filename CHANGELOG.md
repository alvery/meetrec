# Изменения

Версии — по [semver](https://semver.org/lang/ru/). До 1.0 формат настроек и поведение могут меняться
между минорными версиями.

## [0.6.0] — 2026-11-13

Первый релиз.

### Запись
- Приложение в строке меню macOS (14.2+): две дорожки — микрофон («Я») и системный звук («Они»,
  Core Audio process tap), без бота во встрече.
- Смена устройства или формата посреди записи (AirPods, другой выход) не обрывает запись: новый сегмент
  плюс склейка с тишиной на месте паузы.
- Глобальная горячая клавиша старт / стоп: двойное ⌘ / ⌥ / ⌃ / ⇧ или своё сочетание.
- ★ Метка важного момента: ⌃⌥M во время записи. В транскрипте появляется «★ Отметка», действия
  уделяют ей внимание.

### Календарь
- Кольцо в строке меню: отсчёт до встречи, остаток идущей встречи, во время записи — красное,
  за 5 минут до конца — жёлтое.
- Плашка «Подключиться» за минуту до встречи: проверка микрофона и наушников (mute, Bluetooth-гарнитура)
  и задачи с прошлой встречи той же серии.
- «Записать?», когда встреча идёт и созвон занял микрофон. «Остановить запись?», когда созвон закончился,
  встреча вышла за время или началась следующая («Стоп и подключиться»).

### Обработка
- Локальная расшифровка: whisper.cpp large-v3-turbo + silero VAD, фильтр галлюцинаций на тишине.
- Действия после записи: заметки, задачи, конспект и свои промпты, каждое — свой `.md`, выполняются параллельно.
- Агент для действий — любой OpenAI-совместимый API или свой сервер `meetrec-gateway` (Claude по подписке)
  через SSH-туннель, который поднимается сам. Модель задаётся по умолчанию и для каждого действия.
- «Повторить» после ошибки повторяет только действия, без новой расшифровки. Причина ошибки видна в окне
  и в уведомлении.

### Прочее
- Окно настроек: папка встреч, строка меню, автозапуск, горячая клавиша, действия, агент с проверкой
  в три шага.
- Иконка приложения «Спектр», обложка README.
- Отладочные отчёты по SSH (по желанию) — только технические данные, без аудио и текста.
