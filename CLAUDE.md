# meetrec — инструкции для Claude

- Требования и план — в `SPEC.md`, установка и запуск — в `README.md`.
- **После изменения кода — один раунд `/code-review high`.** Сразу чинить только серьёзное на основном
  сценарии (потеря данных, падение, неверный результат в обычном случае); редкие сценарии — в бэклог SPEC.md.
  Исправления повторно не ревьюить, если правка небольшая. Не зацикливаться: без реального запуска на маке
  ревью больше одного раунда почти бесполезно.
- Минимализм: никаких функций сверх SPEC.md без согласования.
- Swift-код собирается только на macOS (`swift build -c release`); после изменений в `Sources/` обязательно собери и проверь.
- **Отладочные отчёты** с мака приходят по SSH на сервер разработки в `~/meetrec-reports/*.md`
  (rec.log, process.log, устройства, параметры файлов). Когда пользователь пишет «посмотри репорты» —
  читай новые файлы оттуда, чини, после фикса перемещай обработанные в `~/meetrec-reports/done/`.
