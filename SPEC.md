# meetrec — требования и план

## Цель
Личная замена Shadow (shadow.do) только для созвонов в Zoom / Google Meet.
Собрать один раз, без подписки, без лишнего: минимум нагрузки во время созвона,
вся тяжёлая работа — после.

**Пользователь:** один разработчик, MacBook M2 / 16 ГБ, созвоны на русском с английскими терминами.

## Принципы
- Во время созвона — только запись. Транскрипция и AI — после.
- Каждый шаг конвейера — подключаемая команда (транскрипция, заметки).
- Всё хранится в обычной папке Markdown: `~/Meetings/<дата>-<название>/`.
- Промпты — текстовые файлы, без UI.
- Заметки по умолчанию через `claude -p` (уже оплаченная подписка), альтернативы — AI-шлюз или локальная модель через `NOTES_CMD`.

## Не делаем
Голосовой ввод, скиллы по хоткею, Quick Access, чат, мультиплатформенность, командный режим.

### Этап 2 — запись внутри приложения
- Перенести `rec` в приложение, кнопка старт/стоп, таймер `● 23:14` в строке меню
- Автостарт: событие календаря идёт + микрофон занят (kAudioDevicePropertyDeviceIsRunningSomewhere)
- Автостоп: микрофон освободился / встреча закончилась
- Папка называется по названию события; `meta.md` с участниками
- Хоткей «метка» — отметка важного момента в таймлайне
- Правила «не записывать» (по названию / участникам)
- Подпись приложения (бесплатный Apple ID), чтобы разрешения не сбрасывались при пересборке

### Этап 3 — обработка
- Автозапуск обработки после стопа, уведомление «заметки готовы»
- Участники из календаря → в промпт (1:1 — «Они» = единственный собеседник)
- Метки из таймлайна → в промпт
- Словарь для whisper (`--prompt`): имена участников + термины проекта
- Удаление аудио после транскрипции (настраиваемо)

### Этап 4 — по всей истории
- `CLAUDE.md` в корне `~/Meetings` — описание структуры, чтобы спрашивать `claude` про всю историю

- `decisions.md` — журнал технических решений
- Еженедельная сводка по пятницам
- Задачи в Apple Reminders; ссылки на тикеты (`PROJ-123`, `#456`)

## Технические заметки
- Системный звук: `CATapDescription(stereoGlobalTapButExcludeProcesses:)` + private aggregate device (macOS 14.2+). Запасной вариант — ScreenCaptureKit (нужно разрешение на запись экрана).
- Транскрипция: whisper.cpp + `ggml-large-v3-turbo` (Metal). Запасной вариант по скорости — Parakeet v3.
- Каждая дорожка транскрибируется отдельно, склейка по `offsets.from`.
